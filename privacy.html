Politique de confidentialité — Nexo Dernière mise à jour : 17/08/2026 Cette politique décrit comment Nexo traite les données dans le cadre de son fonctionnement. 1. Données traitées Nexo traite uniquement les données nécessaires à son fonctionnement : jetons d'accès API (TikTok, services tiers utilisés pour la génération de contenu), et le contenu généré (textes, fichiers audio, vidéos). 2. Stockage Les données sont stockées localement sur l'appareil de l'utilisateur. Aucune donnée n'est transmise à des tiers en dehors des services strictement nécessaires au fonctionnement de l'application (API TikTok, API de génération de contenu utilisées). 3. Aucune collecte tierce Nexo ne collecte, ne vend, ni ne partage de données personnelles avec des tiers à des fins commerciales ou publicitaires. 4. Sécurité Les jetons d'accès et clés API sont conservés de manière confidentielle et ne sont utilisés que pour les appels nécessaires au fonctionnement de l'application. 5.
